# Portfolio Website

A fast and responsive portfolio website built with Next.js, showcasing my projects, skills, and experience in a clean and modern UI. Nodemailer is used to send the response through form submission.

## Installation

1. Clone the repository: `git clone https://github.com/AmiteshSingh45/PortFolio-Nextjs.git`
2. Navigate to the project directory: `cd portfolio-website`
3. Install the dependencies: `npm install`

## Usage

1. Start the development server: `npm run dev`
2. Open your browser and visit `http://localhost:3000` to view the website.

## Dependencies

- Next.js
- Tailwind CSS
- React
- React Icons
- TypeScript
- **Nodemailer** (for form submissions)
